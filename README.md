# Electron App Scaffold

## Getting Started

### Prequisites
Make sure you have [Node.js](https://nodejs.org) installed on your machine.


### Installation
To launch the window shell ensure all dependencies are installed with `npm install` and 
run with `npm start`

### Landing
Starting the application you will land on a project creation/selection page. choosing to create a
a new project will prompt you to choose a project directory with the file explorer. Currently this
is done manually and will be expected to change when the app is deployed and we prompt the user to
choose a dedicated directory during setup.

In this version selecting/creating a project will switch to the video editor screen but there is 
currently no functionality. Projects are currently not able to be deleted as well.
